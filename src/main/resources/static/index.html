① 一次请求走过的四层

由外向内 · 先看骨架
浏览器Vue 3 / fetch
→
安检口Interceptor + JWT
→
Controller接请求 / 返 JSON
→
Service业务规则 + 缓存
→
MapperMyBatis 写 SQL
→
H2 数据库5 张表

白话：浏览器发一句话 → 安检口先验通行证 → Controller 只负责「收和回」→ Service 决定怎么做（要不要走缓存）→ Mapper 把动作翻译成 SQL → 数据库真正存数据。写操作要带 Authorization: Bearer <token>，读操作公开。

层技术白话解释
